# Stuck in a Dream

A free first-person horror game made in 48 hours for a game jam, in Unreal Engine 5.

**Play it:** https://tylerkoa.github.io/stuck-in-a-dream/ (download for Windows 10/11, 64-bit).

You woke up in a forest that never ends, under a swirling purple sky. Find the three portal pieces, each locked behind a surveillance camera fed by a generator. Use your goggles to find the generators, shoot them, and take the pieces. Drones hunt you, spiders leap for your face, and something made of tar and old computer windows follows you through the trees. Don't keep looking at it.

## Install

1. Download `StuckInADream-Windows.zip` from the [latest release](https://github.com/TylerKoa/stuck-in-a-dream/releases/latest).
2. Unzip it anywhere and run `HorrorGameJam10_23.exe`.
3. If Windows says it protected your PC (the game isn't code-signed), click **More info**, then **Run anyway**.

Needs a DirectX 12 graphics card.

## Controls

| Key | Action |
| --- | --- |
| WASD / mouse | Move / look |
| Left click / right click | Shoot / aim |
| 1 / 2 | Pistol / goggles |
| F | Flashlight |
| R / T | Reload / inspect |
| E | Take a portal piece |
| Space | Jump (skips the opening) |
| M | Pause |
